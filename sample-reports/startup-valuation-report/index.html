Sample Startup Valuation Report

This sample shows how we structure a valuation report for a startup raising funds: purpose and basis first, then the assumptions, the working for each method, a sensitivity table and a conclusion with its limits.

Illustrative example: fictional company, not a client. Demo Naturals Private Limited (fictional D2C brand, Ahmedabad). Every number is invented. It must not be used for any decision.
